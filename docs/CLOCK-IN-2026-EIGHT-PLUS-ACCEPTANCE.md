## Fastest path to quality

1. **P0 real Devnet action:** Use independently controlled legitimate Guardian and Beneficiary wallets. Create or verify Charter/Mandate/rule, fund a demo-token vault, sign the 5-unit transfer, independently verify RPC transaction and before/after token balances. Never request someone else's wallet recovery material.
2. **P0 differentiator:** Execute real out-of-bounds denial, exact Guardian approval, exact-use consequence, mutation and replay rejection. Verify state and transaction signatures, not only relay statuses.
3. **P0 mobile delivery:** Verify a standalone release-mode APK tied to the exact source SHA. Read-only judge tour must query real sample-family Devnet accounts and must never sign anything. A new binary does not become physical evidence until device-tested.
4. **P0 submission:** Stable public video and links, honest labeled footage, GitHub main README, APK download, and confirmed portal receipt. Submit well before deadline even if core G1 is unfinished. No fiction.
5. **P1 extra bounty:** Optional SKR only if real holder and usefulness are demonstrated. Devnet SOL is not Mainnet SKR. Avoid forcing unrelated integrations.
