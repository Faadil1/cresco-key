## Project name
CRESCO Key

## Short description
Freedom with Boundaries. CRESCO Key is an Android-first Solana Mobile app exploring everyday autonomy within an onchain family spending Key. A Guardian can review one exact exceptional payment rather than silently expanding standing limits.

## Major new mobile development (answer the applicable “IF NO” field)
CRESCO Key is a new React Native / Expo Android application adapted from an existing CRESCO onchain authorization concept, not simply a web wrapper. The significant native mobile development includes Mobile Wallet Adapter connection and message signing, camera-based Solana Pay intent capture, exact token/amount/recipient review, separate Young Person and Guardian experiences, secure local storage for coordination capabilities, a wallet-free read-only Devnet Key inspection tour, failure/recovery screens, and an installable standalone Android APK. The source includes an exact Guardian one-time onchain authorization path. The latest candidate passed Mobile CI, G1 preflight, emulator smoke, MWA session and APK build. Separately controlled developer signers verified an in-bounds token movement, a standing-limit refusal and an onchain allowance grant. Exact one-time redemption and replay on the new program are an open blocker, not claimed as working end to end.

## SKR integration
Yes — optional, read-only **SKR Charter Atelier**. With a connected wallet, the app checks the official SKR token mint on Solana Mainnet using public account data. A detected holder can access family financial-boundary discussion prompts and build a shareable, read-only review of a separately inspected live Devnet Key (caps, usage, nonce and role). SKR does not transfer assets, modify Key authority or unlock the core app. No real physical-device SKR-holder use is claimed.
